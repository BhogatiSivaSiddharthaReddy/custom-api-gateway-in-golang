# custom-api-gateway-in-golang
A custom API Gateway written in Go to deepen understanding of networking, HTTP internals, and distributed system design, featuring routing, middleware chaining, authentication, and rate limiting.

## Goal

This project is built as a hands-on learning exercise to deeply understand:

- How HTTP servers work internally
- Request routing and reverse proxying
- Middleware design patterns in Go
- Authentication and rate limiting mechanisms
- Network-level concepts used in API gateways
- Building scalable and extensible backend systems
